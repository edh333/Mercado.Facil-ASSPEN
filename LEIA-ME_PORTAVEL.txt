# INSTRUÇÕES PARA USO VIA PENDRIVE (MODO PORTÁTIL)

Este sistema é 100% portátil: funciona em qualquer computador Windows
sem instalar nada (usa só o navegador, que já existe no Windows).

## Estrutura da pasta

    portatil\
      Iniciar-Offline.bat      <- dê DOIS cliques para abrir o sistema
      servidor-offline.ps1
      LEIA-ME_PORTAVEL.txt     <- este arquivo
      dist\                    <- o sistema compilado (não mexa aqui)

## Como iniciar

1. Copie a pasta "portatil" INTEIRA para o pendrive.
2. No computador da venda, abra o pendrive e dê dois cliques em
   Iniciar-Offline.bat
3. O sistema abre no navegador, direto na tela de LOGIN DO ADMIN.

## IMPORTANTE — primeira vez em cada computador

- A PRIMEIRA vez precisa de INTERNET neste computador: entre com o
  login do administrador e espere os produtos/clientes carregarem.
  Eles ficam salvos no cache do navegador da MÁQUINA (não no pendrive).
- Trocou de computador ou de navegador? Precisa de internet de novo,
  uma única vez, para "ensinar" os dados àquela máquina.

## Sem internet (venda offline)

- Abra pelo Iniciar-Offline.bat e use normalmente.
- As vendas ficam numa fila local e aparecem no painel como pendentes.
- PIX com usuário selecionado funciona; FIADO 30 dias precisa de
  internet (valida a senha mestra no servidor).

## Quando a internet voltar

- O sistema ATUALIZA E SINCRONIZA SOZINHO:
  * as vendas feitas offline vão para a nuvem (sem duplicar);
  * produtos, saldos e pedidos novos são baixados automaticamente.
- Pode deixar o sistema aberto (sincroniza na hora) ou fechar e
  reabrir depois (sincroniza ao abrir).

## Backup

- Sempre que possível, em Configurações > Manutenção, faça um
  "Backup Completo" e guarde o arquivo no pendrive como garantia.

## Atualizar o sistema no pendrive

- No computador de origem (onde tem o código), rode criar-portatil.bat
  e copie a pasta "portatil" de novo para o pendrive, substituindo a
  antiga. Nunca misture a pasta nova por dentro da antiga no meio.
